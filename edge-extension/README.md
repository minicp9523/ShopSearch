# Edge 擴充功能安裝

1. 在 Edge 開啟 edge://extensions/。
2. 開啟左側的「開發人員模式」。
3. 點選「載入解壓縮的擴充功能」。
4. 選擇 edge-extension 資料夾。
5. 將「露天價格通知」釘選在工具列。
6. 點擴充功能圖示，輸入 Discord Webhook URL、確認清單，然後儲存。
7. 在露天商店查詢頁完成登入與 Cloudflare 驗證。
8. 開啟擴充功能並按「開始本輪查詢」；擴充功能會依清單逐項使用網站原生查詢按鈕。

使用者必須自行登入、完成 Cloudflare 驗證並送出查詢。擴充功能只讀取已顯示的 #_tbody 結果，不會自動查詢、操作驗證或儲存 GNJOY 帳號密碼。

「發送 Discord 測試」按鈕會立即向設定的 Webhook 發送一則測試訊息。

若網站要求新的 Cloudflare 驗證，擴充功能會顯示等待狀態。使用者必須在頁面自行完成驗證；擴充功能不會操作或繞過驗證。

查詢明確顯示「查無資料」時，會略過商品間隔並立即進入下一件；有資料時才等待設定的間隔。
